# 通知

サイドバーの **通知** グループはアプリのメッセージセンターで、4 つのサブページ (**返信**、**申請**、**いいね**、**評価**)を含みます。未読メッセージは青い角バッジでサイドバーの対応グループとサブ項目にリアルタイム表示され(99 を超えると `99+` 表示)、コミュニティの動向がひと目でわかります。

## 返信

「コメント / 返信 / いいね」の 3 種類の通知を集約し、対象は Mod とディスカッションの 2 か所にまたがります:

- **未読の青いドット + 角バッジ**。「すべて既読にする」に対応;
- 通知カードは本文の先頭画像を自動抽出してサムネイルにし、テキストのみの概要は自動で切り詰めます;
- 操作者のアバターと日時を表示;
- **クリックで即ジャンプ** —— 自動的に既読にし、対応する Mod 詳細またはディスカッションの対象コメント位置へ移動します。返信の前後関係を見失うことはもうありません;
- ページング閲覧に対応。

## 申請

作者視点の**保留中の編集申請**キューです:

- 申請範囲(基本情報 / 言語ファイル(すべて)/ 特定言語)、対象 Mod、申請者、申請理由と日時を表示;
- ワンクリックで**承認 / 拒否**。承認されると申請者は申請範囲どおりに Mod のコンテンツメンテナンスに参加できます([作者向け · 編集権限システム](/ja/guide/workshop/my#編集権限システム)を参照)。

## いいね

自分がいいねした Mod のリストで、標準的なワークショップカードで表示され、クリックで直接詳細に入ります:

- データは**ローカル SQLite キャッシュを優先的に読み込み**、最初に空のときだけリモート DB を照会し、その後キャッシュに書き戻します —— ページを開くとほぼ待ち時間なし;
- 手動リフレッシュが可能。詳細ページでいいねを解除すると、リストに戻った際に自動で同期;
- 1 行あたりの数の独立した設定を持ちます。

## 評価

自分が評価した Mod のリストで、仕組みは「いいね」と同じです:ローカルキャッシュ優先、手動リフレッシュ、詳細ページで評価を削除するとリストも同期更新されます。

::: tip ページのプリロード
通知センターの 4 つのサブページ(およびワークショップの 4 つのサブページ)の間は**プリロードチェーン**が採用されています:現在のページがアクティブになると次ページを自動でプリマウントし、切り替え時に待ち時間なしで即座に表示。マウント済みのページは切り替え時に非表示にするだけで破棄されず、再び表示されたときはデータを強制リフレッシュするため、速い上に古くなりません。
:::
