# クイックスタート

SFMMM は **Tauri 2** ベースの Windows デスクトップアプリで、*Secret Flasher Manaka* シリーズ向けに開発されています。中でも **『*SecretFlasher Manaka 2*』** は、シリーズ現行の大幅改良版(現在のプレイヤーが主に遊んでいるバージョン)です。SFMMM はまさにこの作品を中心に据えたワンストップの Mod 管理体験を提供します:ローカル Mod の有効 / 無効化、ワークショップの閲覧・購読、コミュニティディスカッション、通知センターを網羅し、v1 / v2 の 2 系統のカスタム任務フォルダエコシステムにも対応します。

## システム要件

- Windows 10 / 11
- インストール済みのゲーム *Secret Flasher Manaka*(公式最新版 v1.1.3 を推奨。アプリはゲーム本体のハッシュを自動検証します)

## アプリの入手

[GitHub リポジトリ](https://github.com/b9348/sfmmm) の Releases ページから最新のインストーラをダウンロードしてください。

アプリにはサイレントな自動更新が内蔵されています:起動時に自動で新バージョンを検出し、バックグラウンドでマルチスレッドダウンロード。完了後は次回起動時に自動で適用されるため、手動での再インストールは不要です。また、[設定ページ](/ja/guide/settings)から手動で更新を確認でき、デフォルトのダウンロード元 / GitHub / 夸克网盘 の 3 つのチャンネルから選択できます。

## 初回起動ウィザード

SFMMM を初めて起動するとガイド画面が表示されます。手順は 2 つだけです:

1. **ゲームディレクトリを選択** —— 選択したディレクトリ内に `SecretFlasherManaka.exe` が存在するかを検証し、パスが有効であることを確認します;
2. **UI 言語を選択** —— 中文 / English / 日本語。

完了するとメイン画面に入れます。ゲームディレクトリはいつでも[設定ページ](/ja/guide/settings)で変更できます。

## 画面レイアウトの概要

メイン画面は Windows 風のサイドバーナビゲーションで、上から順に次のようになっています:

| エリア | 内容 |
| --- | --- |
| 上部 | 現在のログインユーザー(未ログイン時は「ログイン / 登録」を表示)。クリックでプロフィールを開いたり、プロフィール編集やログアウトが可能 |
| サイドバー | 3 つのグループ:**ローカル Mod**、**ワークショップ**、**通知**。各グループの下に対応するサブページ |
| サイドバー下部 | **ゲームを起動** ボタン、テーマ切替(ライト / ダーク / システム追従)、**設定** エントリとバージョン番号 |
| コンテンツエリア | 現在のページのコンテンツ。リフレッシュ後も表示位置を保持 |

サイドバーは左上のハンバーガーボタンで折りたたみ / 展開できます。折りたたみ状態は記憶され、次回起動時も維持されます。

## ゲームの起動

サイドバー下部の **ゲームを起動** ボタンをクリックすると、ワンクリックでゲームを起動できます。ゲームのパスが未設定の場合は、設定ページで設定するよう促す案内が表示されます。

::: tip ゲーム実行中のヒント
ゲームの実行中にカスタム任務の有効化 / 無効化を行った場合は、ゲーム内で **ALT + F9** を押して任務リストを更新してください。
:::

## ソースコードからのビルド

開発に参加したい場合や自分でビルドしたい場合は、次の手順で行います:

```bash
# 環境要件:Node.js >= 18、pnpm、Rust >= 1.75

pnpm install      # 依存関係のインストール
pnpm dev          # フロントエンドのみ実行
pnpm tauri dev    # デスクトップアプリを実行
pnpm tauri build  # インストーラをビルド
```

プロジェクトは **React 19 + Vite + Fluent UI** のフロントエンドと **Rust** のバックエンドで構成され、ローカルでは SQLite、リモートでは MySQL を使用します。
