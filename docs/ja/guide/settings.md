# 設定

サイドバー下部の **設定** エントリ(または左下のバージョン番号のクリック)で設定ページに入れます。ページは 4 枚のカードで構成され、サイドバー下部にはテーマ切り替えのショートカットもあります。

## UI 言語

中文 / English / 日本語 の間で切り替えられ、保存後にアプリを再起動すると反映されます。初回起動ウィザードで選択した言語もここに記録されます。

## ゲームパス

- **参照して選択**でゲームのディレクトリを指定。アプリがディレクトリの有効性を検証します;
- ゲームディレクトリの**ワンクリックで開く**に対応;
- パスを変更すると、ローカル Mod のスキャンと「ゲームを起動」が自動的に新しいパスを使用します。

## 更新の確認

アプリには完全な自動更新システムが内蔵されています:

- **更新を確認** ボタンは 3 状態で表示:確認中(回転表示)/ ダウンロード中(「ダウンロードをキャンセル」に変化)/ アイドル;
- 新バージョンを検出すると `v現在 → v最新` と表示され、**3 つのダウンロードチャンネル**を提供します:

| チャンネル | 説明 |
| --- | --- |
| デフォルトのダウンロード元 | アプリ内蔵のソース。バックグラウンドタスクでダウンロード |
| GitHub ダウンロード元 | Releases の直リンクを自動解析し、バージョンの一致を検証 |
| 夸克网盘を開く | ブラウザで共有リンクを開いて自分でダウンロード |

- ダウンロードはバックグラウンドタスクで実行され、進捗バー、ダウンロード済み / 総サイズ、リアルタイム速度を表示。いつでもキャンセル可能;
- ダウンロード完了後は「**今すぐ再起動して更新**」または「後で」を選択できます —— 次回起動時に自動で適用され、手動での再インストールは不要;
- 古いインストーラの自動掃除と失敗時のバックオフ機構を内蔵しており、アップグレード体験は手間いらずです。

> アプリはデフォルトでも毎回の起動時に新バージョンを**サイレント検出**し、バックグラウンドでマルチスレッドダウンロードを実行します。新バージョンの準備ができると、サイドバー下部のバージョン番号の横に赤い **NEW** バッジが表示されます。

## アプリ情報

- GitHub リポジトリ([b9348/sfmmm](https://github.com/b9348/sfmmm))を開く;

## テーマ切り替え

サイドバー下部(ゲームを起動ボタンの上)で、UI テーマをすばやく切り替えられます:

- ☀️ **ライト**
- 🌙 **ダーク**
- 💻 **システム追従**

テーマの選択はローカル DB に永続的に保存されます。アプリは Fluent Design スタイルで、ライト / ダークの両テーマとも完全なビジュアル対応が施されています。
