# クラウド · Mod 閲覧

「ワークショップ」グループの最初のサブページ **クラウド** は、完全なクラウド型 Mod ストアです:閲覧、検索、絞り込み、購読ダウンロード、評価コメントまでを一か所で完結できます。

## 閲覧と発見

上部のツールバーに充実した発見機能を備えています:

- **検索** —— キーワード検索。Enter またはボタンクリックで実行;
- **タイプ絞り込み** —— すべて / v1 任務 / v2 任務 / DLL Mod / 複合;
- **並べ替え** —— 最近の更新(編集)/ 新規公開 / いいね数順 / 評価が高い順;
- **時間の向き** —— 新しい順または古い順。設定は永続化されます;
- **1 行あたりの数** —— グリッド密度を自由に調整。

Mod カードには、mod_key、作者(アバター + 名前。クリックすると作者のホームページをポップアップ表示)、作成 / 更新日時、コメント数、いいね数、カテゴリバッジ、評価の星、2 行で省略される概要、および各言語のファイル行(言語バッジ + 名前 + バージョン + サイズ)が表示されます。

## 詳細を即座に開く

詳細ページの表示体験は徹底的に最適化されています:

- **ホバーでプリフェッチ** —— カードにマウスを 700ms 置くか、クリックした瞬間に詳細データのプリフェッチを開始。クリック時にはキャッシュにヒットして即座にレンダリング;
- **オーバーレイ表示** —— 詳細ページはリストの上に重ねて表示され、リストはマウントされたまま維持されます。**戻ってもデータを再読み込みせず、スクロール位置と画像キャッシュもすべて保持**;
- **ナビゲーションスタック** —— 詳細ページ内で他の Mod をクリックするとナビゲーションスタックが維持され、戻る操作ではリストではなく前の詳細に戻ります。マウスのサイドボタン(戻るボタン)にも対応;
- **次ページのプリフェッチ** —— 現在のページの表示が完了すると次ページを自動でプリリクエストし、ページ送りでローディングを待たせません。

## Mod 詳細ページ

詳細ページの情報は充実しています:

- 作者プロフィールカード(作者が公開したすべての Mod、総ダウンロード数、総いいね数を確認可能);
- **星評価** —— ログイン後は直接評価や評価の取り消しが可能。平均点と評価人数はリアルタイムに更新;
- 作成 / 更新日時、ダウンロード回数;
- **多言語の説明文** —— 上部の言語チェックボックスで表示を切り替え。翻訳のない言語はグレーアウトして表示され、詳細説明は **Markdown とリッチテキスト**の 2 形式に対応;
- **ライトボックス大画像** —— 説明文内の画像をクリックすると大画像プレビューになり、ズームにも対応。

## 購読ダウンロード

「利用可能なバージョン」欄には言語ごとのファイルが一覧表示され(ハッシュの先頭 8 桁を確認可能)、インストールボタンは 3 状態で表示されます:

- **インストール** —— 未インストールの場合;
- **更新** —— ローカルバージョンが古い場合(セマンティックバージョニングに基づき比較);
- **インストール済み / 再インストール** —— インストール済みの場合で、強制再インストールも可能。

ダウンロードタスクは Rust バックエンドで実行され、進行状況バーに「待機中 / ダウンロード中(パーセント + 速度)/ 解凍中 / 記録中」がリアルタイムに表示されます。**ページを離れてもタスクは通常どおり完了し**、すべての記録は [購読履歴](/ja/guide/workshop/records) ページで一括管理できます。

インストール済みの Mod ではさらに、インストールフォルダを開く(エクスプローラー上で manifest 内のファイルを自動ハイライト)、ファイルリストの表示、ワンクリックでの購読解除(manifest に基づきファイル単位で正確に削除し、空ディレクトリも掃除)が可能です。

## いいねとコメント

- **いいね** —— カードと詳細ページにあるフローティングのハートボタン。ワンクリックでお気に入り登録。ログイン検証付き;
- **コメント** —— スレッド返信(「返信 N 件を表示」の折りたたみ展開)、新しい順 / 古い順の並べ替え、Markdown による整形、ペーストまたは挿入した画像の画像ホスティングへの自動アップロード、画像ライトボックスに対応。自分のコメントは編集 / 削除可能。投稿者は配下のすべてのコメントを削除でき、コメント主は自分のコメントに付いた返信を削除できます。通知からジャンプした場合は対象のコメント位置まで自動スクロールします。

## 編集申請

作者以外のユーザーが内容の問題を見つけた場合、作者に編集申請を送信できます([通知 · 申請](/ja/guide/notify)を参照)。承認されると、その Mod の情報メンテナンスに参加できるようになります。
