# ディスカッション

「ワークショップ」グループの 2 つ目のサブページ **ディスカッション** は、Mod 体系から独立したコミュニティ掲示板です:投稿して交流、投票で調査、いいねでリアクションできます。

## 投稿リスト

リストページでは次の操作に対応します:

- **検索** —— キーワードで投稿をフィルタリング;
- **並べ替え** —— 最近の更新(編集)/ 新規投稿 / いいね数順 / ブースト数順;
- **時間の向き** と **1 行あたりの数** の調整。

投稿にはログインが必要で、未ログインのまま投稿をクリックすると自動でログインダイアログが表示されます。投稿詳細も**オーバーレイ + プリフェッチキャッシュ**による即時表示モードを採用し、`#/discuss/<id>?comment=<cid>` 形式のリンクで特定のコメント位置に直接ジャンプできます。

## 投票投稿

投稿時に「通常投稿」または「投票投稿」を選択できます。投票投稿は 3 種類の投票タイプに対応します:

| タイプ | 説明 |
| --- | --- |
| 単一選択 | 1 人 1 票 |
| 複数選択 | 選択可能数の最小 / 最大値を設定可能 |
| 数値評価 | 最小値 / 最大値 / 刻み幅を設定可能 |

投票結果の公開設定は「常に表示」または「投票後に表示」を選択可能。投票後は結果が**バーチャート**で表示され、票の変更にも対応。参加人数と平均点も表示されます。

## ブースト Boost

Discourse 風の軽量インタラクション:

- 各人は各投稿につき最大 1 件、16 文字以内のブーストフレーズを付けられます;
- 「アバター + フレーズ」の角丸タグとして投稿の下に集約表示;
- 自分のブーストはハイライト表示され、いつでも削除可能;
- あくまで態度の表明であり、投稿の並び順には影響しません。

## 投稿詳細

- 本文は **Markdown** に対応し、画像をクリックするとライトボックスで大画像表示;
- 自分の投稿はいいね、編集 / 削除が可能;
- コメント欄は Mod コメントと同一のコンポーネントを共有:スレッド返信、Markdown、画像アップロード、編集・削除の権限ルールも完全に同じです。

## マイディスカッション

[マイページ · 作者向け](/ja/guide/workshop/my) では、自分が投稿した投稿とすべての返信を確認でき、時間降順の単一リストにまとめられます。「投稿 / 返信」のラベルで区別され、返信項目をクリックするとディスカッション詳細へ直接ジャンプし、対象のコメント位置までスクロールします。
