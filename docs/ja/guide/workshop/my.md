# マイページ · 作者向け

「ワークショップ」グループの 3 つ目のサブページ **マイページ** は、Mod 作者とディスカッションユーザー向けのコンテンツ管理バックエンドです。「マイ Mod」と「マイディスカッション」の 2 つのサブタブがあります。

## Mod の公開

公開フローはクリエイター向けに細かい配慮が施されています:

### 基本情報

- **mod_key** —— Mod の一意な識別子。入力時に自動で重複チェック;
- **カテゴリ** —— v1 任務 / v2 任務 / DLL Mod / 複合。

### 多言語コンテンツブロック

各言語ごとに、独立した完全なコンテンツを 1 セット記入します:

- 名前、概要、詳細説明;
- 詳細説明は **Markdown** または**リッチテキストエディタ**(太字 / 斜体 / 見出し / リスト / 引用 / 画像などのツールバー)のデュアルモードに対応;
- changelog とバージョン番号;
- 説明文に挿入する画像は「先にプレースホルダー、後で画像ホスティングへアップロード、最後に URL を置換」というフローで処理され、アップロード待ちで執筆が中断されることはありません。

### ファイル選択(カテゴリに応じてスマートに適応)

| カテゴリ | 選択方式 |
| --- | --- |
| v1 任務 | json / code / txt / zip を複数選択。`CustomMissions` からの相対パスを保持 |
| v2 任務 | フォルダを選択し、全ファイルを再帰的に収集 |
| DLL Mod | DLL ファイルを選択 |
| 複合 | フォルダとファイルを混在可能。ゲームルートからの相対パスを保持 |

**追加時に重複を除去**してファイル項目を統合できるため、何度調整しても最初からやり直す必要はありません。

### 公開フロー

mod_key のチェック → レコード作成 → フロントエンドで圧縮してパッケージング → アップロード(単一ファイル上限 20MB、R2 権限ユーザーは 100MB)→ 古いファイルの掃除。全体の進捗はポップアップで可視化されます。

## Mod の編集

- **権限に応じて**編集範囲を絞り込み(基本情報 / すべての言語 / 指定言語);
- バージョン番号を変更したのにファイルを選び直していない場合は、警告が表示されて操作がブロックされ、「バージョンだけ変えてファイルを送っていない」というミスを防止;
- 保存すれば置き換えられる、統一されたフロー;
- 削除された説明文の画像は自動的に画像ホスティングから掃除され、孤児ファイルを残しません;
- Mod の削除時は確認ダイアログが表示され、ファイル単位で削除の進捗を表示します。

## 編集権限システム

作者は各 Mod に 4 種類の協力モードを設定できます:

| モード | 説明 |
| --- | --- |
| 自分だけが編集可能 | デフォルト。完全にプライベート |
| 全開放 | 誰でも編集できる |
| 言語別の編集開放 | どの言語をコミュニティのメンテナンスに開放するかを指定 |
| 編集申請制 | どの言語を申請により編集権を取得できるようにするかを指定 |

コミュニティメンバーの申請は [通知 · 申請](/ja/guide/notify) の保留リストに入り、作者は承認または拒否できます。承認された申請者は、その範囲のコンテンツメンテナンスに参加できるようになります —— これにより、**Mod の多言語翻訳をコミュニティの協力で進める**ことが可能です。

## マイディスカッション

投稿と返信(スレッド返信を含む)が時間降順の単一リストにまとめられ、「投稿 / 返信」のラベルで区別されます。クリックするとディスカッション詳細へ移動し、返信項目は対象のコメント位置まで自動スクロールします。
