# 存档管理

「本地模组」分组的第四个子页面 **存档**,提供游戏存档的表格化管理。存档目录下的 `.sd` 文件以清晰的表格列出,包含文件名、类型、大小、修改时间与操作列。

## 类型标识

每个文件都有彩色类型徽章,一眼区分:

| 徽章 | 类型 | 说明 |
| --- | --- | --- |
| 🔵 蓝色 | 存档 | 游戏进度文件(`.sd`) |
| 🟡 黄色 | 设置 | 游戏配置文件 |
| 🟢 绿色 | 备份 | 通过本页面创建的备份(`.sd.bak`) |

## 备份与还原

- **备份** —— 一键把 `{name}.sd` 复制为 `{name}.sd.bak`,原文件保持不动;
- **还原** —— 从备份恢复,还原前会进行指纹校验;若同名存档已存在,会弹出确认对话框明确提示「还原后将覆盖它」,确认后才执行覆盖还原,避免误操作;
- **内联重命名** —— 直接在表格行内编辑文件名,Enter 确认、Escape 取消;
- **打开存档目录** —— 在资源管理器中打开存档所在目录;
- **刷新** —— 重新加载列表。

所有操作的结果都会以 Toast 通知反馈 —— 成功提示、失败原因一目了然,不用担心误删坏档。
