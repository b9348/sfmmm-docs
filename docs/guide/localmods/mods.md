# 模组管理

「本地模组」是侧边栏的第一个分组,对应应用内的本地文件管理中心。其中 **模组** 子页面管理 `BepInEx/plugins` 目录下的 DLL 模组与配置文件 —— 应用会隐藏 BepInEx 的目录层级,直接呈现模组列表。

## 模组列表

进入页面后自动扫描本地模组,每一条记录展示:

- **类型徽章** —— 区分 DLL 模组与普通配置文件,文件夹配置亦有专属徽章;
- **工坊徽章** —— 若该文件属于某个创意工坊订阅,会额外显示订阅来源、版本号、语言与云端评分星级;
- **搜索** —— 关键字快速过滤;
- **状态统计** —— 底部状态栏显示当前模组数量,列表头部显示最近一次扫描时间。

## 启用 / 禁用

不需要卸载即可临时停用某个模组:

- **单个启停** —— 切换文件启用状态,实现方式为将文件重命名(如 `.json` → `[ban]json`),前端归一化后依然能识别归属,列表就地更新、无需重新扫描;
- **一键禁用全部 / 一键恢复全部** —— 批量切换所有模组的启用状态。

::: tip 游戏运行时的注意事项
若游戏正在运行,停用或启用自定义任务后需要在游戏中按 **ALT + F9** 刷新任务列表。
:::

## 文件管理

- **Windows 风格多选** —— 单击单选、Ctrl 逐个切换、Shift 范围选择;
- **打开所在目录** —— 多选时会在资源管理器中一次性**高亮所有选中项**;单选时由后端按真实类型智能裁决(目录则直接进入,文件则打开父目录并高亮),对 junction / 符号链接同样可靠;
- **刷新** —— 重新扫描模组目录。

## BepInEx 前置一键安装

模组页会持续检测运行前置的安装状态,未安装时页面顶部显示警示横幅,点击即可从**内置下载点 / HuggingFace / 蓝奏云**多个下载点一键安装:

| 检测项 | 说明 |
| --- | --- |
| BepInEx 加载器 | 运行 DLL 模组的基础 |
| v1 任务插件(SFM_custom_mission.dll) | 加载 v1 自定义任务所需 |
| v2 任务插件 | 加载 v2 自定义任务所需(中文界面下额外检测中文字体) |
| 去马赛克补丁(rmmosaic) | 可选补丁 |
| Doorstop 版本兼容性 | 不兼容时建议更换为推荐版本 |

下载任务由 Rust 后台执行,**离开页面不会中断,返回时自动恢复进度**,并实时显示百分比、已下载大小与下载速度。

## 工坊订阅联动

本地模组与创意工坊数据双向打通:

- **「创意工坊」徽章** —— 通过安装记录与 manifest 匹配,自动把本地文件识别为工坊订阅,直接显示版本、语言、评分;
- **有更新徽章** —— 云端发布了新版本时提示,可一键**更新到最新版**(就地拉取云端最新文件重装);
- **来源冲突检测** —— 本地文件哈希与云端不一致时显示红色「来源冲突」徽章,识别手动替换或篡改过的文件;
- **组级操作** —— 同一订阅的多个文件自动归入绿色描边分组卡片,组头可一键暂停 / 继续、更新或退订整个分组;
- **前往创意工坊** —— 从本地列表直接跳转到该模组的云端详情页。

## 游戏版本校验

应用内置官方最新版(v1.1.3)游戏主程序的哈希基准,检测到游戏版本不一致时,页面顶部会显示「游戏版本可能不是官方最新版」的警告,帮助排除因游戏版本过旧导致的模组异常。
