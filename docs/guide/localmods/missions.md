# 自定义任务 v1 / v2

「本地模组」分组下的 **v1** 与 **v2** 子页面,分别管理游戏的自定义任务目录 `CustomMissions`(v1)与 `CustomMissions2`(v2),以卡片式文件浏览器的形式呈现。

## 页面结构

两个页面共享同一套文件浏览器能力:

- **面包屑导航** —— 展示当前所在层级,点击任意层级直接跳转;
- **双击进入** —— 双击文件夹卡片进入子目录;
- **卡片形态** —— 文件夹卡显示「N 个文件夹,M 个文件」统计,文件卡显示扩展名徽章与禁用状态徽章;
- **网格密度调节** —— 「每行 X 个」(1–10),偏好会被持久化记忆;
- **噪声过滤** —— 自动忽略 `readme.txt` 等噪声文件,保持列表干净;
- **刷新按钮** —— 随时重新扫描目录。

## 任务文件管理

- **启用 / 禁用** —— 与模组管理一致的重命名机制,单个或批量切换任务的启用状态;
- **多选与定位** —— Windows 风格多选(Ctrl / Shift),一键在资源管理器中高亮选中项;
- **一键禁用全部 / 恢复全部** —— 需要回到原版任务时非常方便。

## 前置检测与安装

v1 / v2 页面各自检测所需的运行前置,未安装时显示警示横幅:

- **v1** —— 检测 BepInEx 加载器与 v1 任务插件(SFM_custom_mission.dll);
- **v2** —— 检测 BepInEx 加载器、v2 任务插件;中文界面用户还会额外检测**中文字体**,避免任务文本显示异常。

所有前置均支持**内置下载点 / HuggingFace / 蓝奏云**多下载点一键安装,后台下载、断点进度不丢失。

## 工坊任务识别

从创意工坊订阅安装的自定义任务会被自动识别并展示:

- 卡片显示「创意工坊」徽章、版本号、语言与评分星级;
- 提供**前往创意工坊查看详情**、**更新到最新版**、**退订**三个快捷操作;
- 同一订阅的任务文件自动分组展示,支持组级一键暂停 / 继续、更新与退订;
- 云端有新版本时显示「有更新」徽章;本地文件被手动改动过则显示「来源冲突」。

## 跨页面定位

从 [订阅记录](/guide/workshop/records) 页点击「在本地模组中查看」,应用会自动跳转到对应子页面,匹配 mod_key 后滚动到目标卡片、居中显示并高亮 2 秒,即使是数百个任务也能立刻找到。
