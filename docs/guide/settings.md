# 设置

点击侧边栏底部的 **设置** 入口(或点击左下角版本号)进入设置页。页面由四张卡片组成,另外在侧边栏底部还有主题切换快捷入口。

## 界面语言

在中文 / English / 日本語之间切换,保存后重启应用生效。首次运行向导中选择的语言也会记录在这里。

## 游戏路径

- **浏览选择**游戏所在目录,应用会校验目录有效性;
- 支持**一键打开**游戏目录;
- 路径变更后,本地模组扫描与「启动游戏」都会自动使用新路径。

## 检查更新

应用内置完整的自动更新体系:

- **检测更新**按钮三态显示:检测中(转圈)/ 下载中(变为「取消下载」)/ 空闲;
- 检测到新版本时显示 `v当前 → v最新`,并提供**三个下载渠道**:

| 渠道 | 说明 |
| --- | --- |
| 默认下载源 | 应用内置源,后台任务下载 |
| GitHub 下载源 | 自动解析 Releases 直链并校验版本一致 |
| 打开夸克网盘 | 浏览器打开分享链接自行下载 |

- 下载为后台任务,显示进度条、已下载 / 总大小与实时速度,可随时取消;
- 下载完成后可选择「**立即重启并更新**」或「稍后」—— 下次启动时自动应用,无需手动重装;
- 自带陈旧安装包自动清理与失败退避机制,升级体验省心。

> 应用默认也会在每次启动时**静默检测**新版本并后台多线程下载,新版本就绪后侧边栏底部版本号旁会出现红色 **NEW** 徽章。

## 主题切换

在侧边栏底部(启动游戏按钮上方)可快速切换界面主题:

- ☀️ **亮色**
- 🌙 **深色**
- 💻 **跟随系统**

主题选择持久化保存在本地数据库;应用采用 Fluent Design 风格,深浅两套主题均有完整的视觉适配。
