# 通知中心

侧边栏的 **通知** 分组是应用的消息中心,包含四个子页面:**回复**、**申请**、**点赞**、**评分**。未读消息会以蓝色角标实时显示在侧边栏对应分组与子项上(超过 99 显示 `99+`),一眼掌握社区动态。

## 回复

聚合「评论 / 回复 / 点赞」三类通知,来源覆盖模组与讨论区两处:

- **未读蓝点 + 角标**,支持「全部标为已读」;
- 通知卡片自动提取正文首图做缩略图,纯文本摘要自动截断;
- 显示操作人头像与时间;
- **点击即跳转** —— 自动标记已读,并定位到对应模组详情或讨论区的具体楼层,回复再也不会找不到上下文;
- 支持分页浏览。

## 申请

作者视角的**待处理编辑申请**队列:

- 显示申请范围(基本信息 / 语言文件(全部)/ 特定语言)、目标模组、申请人、申请理由与时间;
- 一键**批准 / 拒绝**;批准后申请人即可按申请范围参与模组内容维护(见 [作者工作台 · 编辑权限系统](/guide/workshop/my#编辑权限系统))。

## 点赞

你点赞过的模组列表,以标准工坊卡片呈现,点击直接进入详情:

- 数据**优先读取本地 SQLite 缓存**,首次为空才查询远程数据库,之后回写缓存 —— 打开页面几乎零等待;
- 可手动刷新;在详情页取消点赞后返回列表会自动同步;
- 拥有独立的每行数量偏好设置。

## 评分

你评分过的模组列表,机制与「点赞」一致:本地缓存优先、手动刷新、详情页撤评后列表同步更新。

::: tip 页面预加载
通知中心的四个子页面(以及创意工坊的四个子页面)之间采用**预加载链**:当前页面激活时自动预挂载下一个页面,切换即时展示无需等待;已挂载的页面切换时仅隐藏不销毁,回到可见时会强制刷新数据,既快又不会过期。
:::
