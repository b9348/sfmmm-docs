# 我的 · 作者工作台

「创意工坊」分组的第三个子页面 **我的**,是模组作者与讨论区用户的内容管理后台,内含「我的模组」与「我的讨论」两个子标签。

## 发布模组

发布流程为创作者做了大量贴心的适配:

### 基本信息

- **mod_key** —— 模组唯一标识,输入时自动查重;
- **分类** —— v1 任务 / v2 任务 / DLL 模组 / 组合。

### 多语言内容块

每种语言独立填写一套完整内容:

- 名称、简介、详细说明;
- 详细说明支持 **Markdown** 或**富文本编辑器**(粗体 / 斜体 / 标题 / 列表 / 引用 / 图片等工具栏)双模式;
- changelog 与版本号;
- 说明中插入的图片采用「先占位、后上传图床、再替换 URL」的流程,写作不被上传等待打断。

### 文件选择(按分类智能适配)

| 分类 | 选择方式 |
| --- | --- |
| v1 任务 | 多选 json / code / txt / zip,路径相对 `CustomMissions` 保留 |
| v2 任务 | 选择文件夹,递归收集全部文件 |
| DLL 模组 | 选择 DLL 文件 |
| 组合 | 可混合文件夹与文件,路径相对游戏根目录保留 |

支持**追加去重**合并文件条目,反复调整无需从头再来。

### 发布流程

检查 mod_key → 创建记录 → 前端压缩打包 → 上传(单文件限 20MB,R2 权限用户 100MB)→ 清理旧文件,全程进度弹窗可视化。

## 编辑模组

- **按权限裁剪**可编辑范围(基本信息 / 全部语言 / 指定语言);
- 版本号变更但未重新选择文件时会拦截提示,防止「只改版本没传文件」的失误;
- 保存即替换,统一流程;
- 被删除的说明图片会自动从图床清理,不留孤儿文件;
- 删除模组时有确认弹窗,并按文件逐个显示删除进度。

## 编辑权限系统

作者可为每个模组设置四种协作模式:

| 模式 | 说明 |
| --- | --- |
| 仅我自己可编辑 | 默认,完全私有 |
| 全开放 | 任何人都能编辑 |
| 开放语言编辑 | 指定哪些语言开放给社区维护 |
| 需申请编辑 | 指定哪些语言可通过申请获得编辑权 |

社区成员的申请会进入 [通知中心 · 申请](/guide/notify) 待处理列表,作者可批准或拒绝,批准后申请人即可参与对应范围的内容维护 —— 这让模组的**多语言翻译可以由社区协作完成**。

## 我的讨论

发帖与回复(含楼中楼)合并为时间倒序的单一列表,「发帖 / 回复」标签区分;点击跳转讨论详情,回复条目自动定位到对应楼层。
