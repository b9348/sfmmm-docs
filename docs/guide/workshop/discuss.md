# 讨论区

「创意工坊」分组的第二个子页面 **讨论区**,是独立于模组体系的社区讨论版块:发帖交流、投票调研、点赞互动。

## 帖子列表

列表页支持:

- **搜索** —— 关键字过滤帖子;
- **排序** —— 有编辑 / 新发布 / 最多赞 / 助推数;
- **时间方向**与**每行数量**调节。

发帖需要登录,未登录点击发帖会自动弹出登录框。帖子详情同样采用**覆盖层 + 预取缓存**的秒开模式,并支持 `#/discuss/<id>?comment=<cid>` 形式的链接直接定位到具体楼层。

## 投票帖

发帖时可选择「普通帖」或「投票帖」。投票帖支持三种投票类型:

| 类型 | 说明 |
| --- | --- |
| 单选 | 每人投一票 |
| 多选 | 可设置最少 / 最多可选数 |
| 数字评分 | 可设置最小值 / 最大值 / 步进 |

投票结果的可见性可设为「始终可见」或「投票后可见」;投票后以**条形图**展示结果,支持改票,并显示参与人数与均分。

## 助推 Boost

Discourse 风格的轻量互动:

- 每人对每帖最多 1 条、不超过 16 字的助推短语;
- 以「头像 + 短语」的圆角标签形式聚合展示在帖子下方;
- 自己的助推高亮显示且可随时删除;
- 只表达态度,不影响帖子排序。

## 帖子详情

- 正文支持 **Markdown**,图片点击进入灯箱大图;
- 点赞、编辑 / 删除自己的帖子;
- 评论区与模组评论共用同一套组件:楼中楼、Markdown、图片上传、编辑删除权限规则完全一致。

## 我的讨论

在 [我的 · 作者工作台](/guide/workshop/my) 中可以查看自己发布的帖子与全部回复,合并为时间倒序的单一列表,用「发帖 / 回复」标签区分;点击回复条目会直接跳转到讨论详情并定位到对应楼层。
