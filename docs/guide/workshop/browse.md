# 云 · 模组浏览

「创意工坊」分组的第一个子页面 **云**,是一个完整的云端模组商店:浏览、搜索、筛选、订阅下载、评分评论一站完成。

## 浏览与发现

顶部工具栏提供完整的发现能力:

- **搜索** —— 关键字搜索,回车或点击按钮触发;
- **类型筛选** —— 全部 / v1 任务 / v2 任务 / DLL 模组 / 组合;
- **排序** —— 有编辑(最近更新)/ 新发布 / 最多赞 / 评分最高;
- **时间方向** —— 最新在前或最早在前,偏好持久化;
- **每行数量** —— 自由调节网格密度。

模组卡片展示 mod_key、作者(头像 + 名字,可点击查看 TA 的主页弹窗)、创建 / 更新时间、评论数、点赞数、分类徽章、评分星级、两行截断的简介,以及各语言文件行(语言徽章 + 名称 + 版本 + 大小)。

## 详情秒开

详情页的打开体验经过深度优化:

- **悬停预取** —— 鼠标在卡片上停留 700ms 或按下的瞬间即开始预取详情数据,点击时命中缓存立即渲染;
- **覆盖层渲染** —— 详情页叠加在列表之上,列表保持挂载,**返回时不重载数据,滚动位置与图片缓存全部保留**;
- **导航栈** —— 在详情页内点击其他模组,会维护导航栈,返回时回到上一个详情而非列表;鼠标侧键(后退键)同样支持;
- **下一页预取** —— 当前页就绪后自动预请求下一页,翻页免 loading。

## 模组详情页

详情页信息完整:

- 作者资料卡(可查看 TA 发布的所有模组、总下载量与总获赞);
- **星级评分** —— 登录后可直接打分或清除评分,均分与人数实时更新;
- 创建 / 更新时间、下载次数;
- **多语言说明** —— 顶部按语言复选框切换展示;没有翻译的语言置灰标记,详细说明支持 **Markdown 与富文本**两种格式;
- **灯箱大图** —— 说明中的图片点击进入大图预览,支持缩放。

## 订阅下载

「可用版本」区按语言列出文件(可见哈希前 8 位),安装按钮三态显示:

- **安装** —— 未安装时;
- **更新** —— 本地版本较低时(按语义化版本比较);
- **已安装,重新安装** —— 已装场景,可强制重装。

下载任务在 Rust 后端执行,进度条实时显示「等待中 / 下载中(百分比 + 速度)/ 解压中 / 记录中」,**离开页面任务照常完成**,全部记录可在 [订阅记录](/guide/workshop/records) 页统一管理。

已安装的模组还可以:打开安装目录(自动在资源管理器中高亮 manifest 中的文件)、查看文件列表、一键退订(按 manifest 逐文件精确删除并清理空目录)。

## 点赞与评论

- **点赞** —— 卡片与详情页的悬浮红心按钮,一键收藏,登录校验;
- **评论** —— 支持楼中楼(「查看 N 条回复」折叠展开)、按最新 / 最早排序、Markdown 排版、粘贴或插入图片自动上传图床、图片灯箱;可编辑 / 删除自己的评论;楼主可删除帖下所有评论,层主可删除自己楼层收到的回复;从通知跳转进来时自动滚动定位到对应楼层。

## 申请编辑

非作者发现内容问题时,可向作者提交编辑申请(见 [通知中心 · 申请](/guide/notify)),通过后即可参与该模组的信息维护。
