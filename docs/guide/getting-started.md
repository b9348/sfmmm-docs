# 快速开始

SFMMM 是一款基于 **Tauri 2** 的 Windows 桌面应用,面向塞雷卡(*Secret Flasher Manaka*)系列 —— 其中 **「塞雷卡2」** 是系列当前主力游玩的全面改进版。SFMMM 正是围绕它打造的一站式模组管理体验:本地模组启停、创意工坊浏览与订阅、社区讨论、通知中心全覆盖,并同时支持 v1 / v2 两套自定义任务文件夹生态。

## 系统要求

- Windows 10 / 11
- 已安装游戏 *Secret Flasher Manaka*(建议官方最新版 v1.1.3,应用会自动校验游戏主程序哈希)

## 获取应用

前往 [GitHub 仓库](https://github.com/b9348/sfmmm) 的 Releases 页面下载最新安装包。

应用内置静默自动更新:启动时自动检测新版本,后台多线程下载完成后,下次启动时自动应用更新,无需手动重装。你也可以在 [设置页](/guide/settings) 手动检查更新,并从默认下载源、GitHub 或夸克网盘三个渠道任选其一。

## 首次运行向导

首次启动 SFMMM 时会进入引导界面,只需两步:

1. **选择游戏目录** —— 应用会校验所选目录下是否存在 `SecretFlasherManaka.exe`,确保路径有效;
2. **选择界面语言** —— 中文 / English / 日本語。

完成后即可进入主界面。游戏目录随时可以在[设置页](/guide/settings)中更改。

## 界面布局速览

主界面采用 Windows 风格侧边导航,从上到下依次为:

| 区域 | 内容 |
| --- | --- |
| 顶部 | 当前登录用户(未登录时显示「登录 / 注册」),点击可打开个人主页、编辑资料或退出登录 |
| 侧边栏 | 三大分组:**本地模组**、**创意工坊**、**通知**,每组下方为对应子页面 |
| 侧边栏底部 | **启动游戏** 按钮、主题切换(亮色 / 深色 / 跟随系统)、**设置** 入口与版本号 |
| 内容区 | 当前页面内容,刷新后仍保持所在位置 |

侧边栏可通过左上角的汉堡按钮折叠 / 展开,折叠状态会被记忆,下次启动保持不变。

## 启动游戏

点击侧边栏底部的 **启动游戏** 按钮,即可一键拉起游戏。若尚未配置游戏路径,应用会先提示前往设置页完成配置。

::: tip 游戏运行时的小提示
游戏运行期间启用或停用自定义任务后,需要在游戏中按下组合键 **ALT + F9** 来刷新游戏任务列表。
:::

## 从源码构建

如果你想参与开发或自行构建:

```bash
# 环境要求:Node.js >= 18、pnpm、Rust >= 1.75

pnpm install      # 安装依赖
pnpm dev          # 仅运行前端
pnpm tauri dev    # 运行桌面应用
pnpm tauri build  # 构建安装包
```

项目采用 **React 19 + Vite + Fluent UI** 前端与 **Rust** 后端,本地使用 SQLite、远程使用 MySQL。
